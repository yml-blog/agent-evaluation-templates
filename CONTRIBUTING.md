# Contributing

## Suggest a new template

Open an issue with the **Suggest a new template** form. Describe the evaluation problem it solves, the stage where it would be used (design, testing, or release review), and what the template would contain.

## Report a problem or propose a change

Open an issue for errors, unclear guidance, or missing cases. Small fixes can go straight to a pull request; for larger changes, open an issue first so the scope can be agreed.

## Requirements

- Keep templates platform-neutral. Do not assume a single framework or vendor workflow.
- Use only synthetic, generic example data. Do not include data from employers, clients, patients, or production systems, and do not name real organizations or people.
- Do not include credentials, secrets, or internal URLs.
